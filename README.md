 🎓 Student Management System

📌 Project Description

This is a full-stack Student Management System built using ASP.NET Core Web API and Angular.
It allows users to manage student records with CRUD operations.

---

 🚀 Tech Stack

* ASP.NET Core Web API
* Angular
* SQL Server

---

 ✨ Features

* Add Student
* Update Student
* Delete Student
* View Student List

---

📂 Project Structure

```
Student-Management-System/
│
├── Backend/        # ASP.NET Core Web API
├── Frontend/       # Angular Application
└── Database/       # SQL 
```

---

 ⚙️ How to Run

 🔹 Backend

1. Open project in Visual Studio 2022
2. Run the API

---

🔹 Frontend

```bash
npm install
ng serve
```

🔹 Database

* Run SQL Commands
